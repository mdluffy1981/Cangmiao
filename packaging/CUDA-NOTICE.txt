Requirements:
  NVIDIA GPU and a compatible NVIDIA driver.
  The driver must support CUDA 12.5. No separate CUDA Toolkit or cuDNN
  installation is required: the runtime libraries below are bundled next to
  engine\cuda\katago.exe. If no NVIDIA GPU is available, use the standard CPU
  or OpenCL build.
